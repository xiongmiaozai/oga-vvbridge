技术说明 · 通道映射与格式（点击展开）

LabPBR _s → MERS 四通道（依据 01_LabPBR材质标准.md、13_纹理文件通道与格式详解.md）：

源目标公式
R 感知平滑度 sB 粗糙度255·pow(1−s/255, 2)
G F0 / 金属 gR 金属度g≥230 ? 255 : 0（F0 信息丢失）
A 自发光 aG 自发光a=255 ? 0 : round(a·255/254)
B SSS / 孔隙率 bA 次表面散射b≥65 ? (b−65)·255/190 : 0
—金属/SSS 互斥metal ≥ sss → sss = 0

输出格式：_mers.tga 必须是 32-bit BGRA、左下原点、8 alpha bits。PNG 改后缀无效，必须重排通道并翻转行序（Alpha=0 有语义，Photoshop 优化 PNG 会丢 RGB）。texture_set.json 固定 format_version:"1.21.30" + color + metalness_emissive_roughness_subsurface；manifest.json 必须带 capabilities:["pbr"]。解码全程为非预乘逐字节读取：alpha=0 像素的 R/G/B（平滑度/F0/SSS）原样保留，不会像 canvas 预乘那样被抹成 0。

法线：LabPBR _n 的 B 存 AO、A 存高度，Z 用 sqrt(1−dot(n.xy,n.xy)) 重建；DirectX Y− 与 VV 同向，不需翻转 G（该结论来自第三方转换器实现，非 Mojang 官方明文，故保留开关）。

已知信息损失：介电质 F0（G 0–229）、孔隙率（B 0–64）、材质 AO、POM 高度 —— VV 无对应通道，转换报告会列出丢弃的像素数。
