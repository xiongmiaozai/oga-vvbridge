# 灵动视效：除贴图外还能编辑什么（基于官方样例包实物）

> 整理日期：2026-11-16　|　来源：Mojang 官方样例包 `bedrock-samples v1.26.70.23-preview-full.zip`（172MB）实物 + `07_生物群系自定义.md` 官方文档全文
> 方法：从官方包内 `resource_pack/{atmospherics,color_grading,lighting,water}/` 与 `metadata/json_schemas/` 提取真实 schema，**不凭空捏造字段**。配套可编辑模板在 `LabPBR2VV/vv_templates/`。

---

## 一、VV 资源包 = 贴图层 + 配置层

转换器目前只做**贴图层**（texture_set / MERS / 法线 / `pbr/global.json` 回退）。"除贴图外"指的是**配置层**，全部是 JSON，共 5 类效果配置 + 群系绑定 + 全局回退。

## 二、五类效果配置（官方样例包实物核对）

| 类别 | 目录 | 官方包名下的实例数 | 官方全局默认文件 |
|---|---|---|---|
| 大气 atmospherics | `atmospherics/` | 18 | `atmospherics/atmospherics.json` |
| 色彩分级 color_grading | `color_grading/` | 15 | `color_grading/color_grading.json` |
| 光照 lighting | `lighting/` | 16 | `lighting/global.json` |
| 水体 water | `water/` | 1 | `water/water.json` |
| 天空盒 cubemaps | `cubemaps/` | 0（此版本未附带实例） | — |

（另有 `pbr/global.json` 全局材质回退，属贴图层，见 `13_` 号。）

### 1. 大气 `minecraft:atmosphere_settings`（format_version 1.21.40）
- `horizon_blend_stops`：`min`/`start`/`mie_start`/`max` 四组停靠点（均为时间关键帧）
- `rayleigh_strength`：瑞利散射强度
- `sun_mie_strength` / `moon_mie_strength`：太阳/月亮米氏散射
- `sun_glare_shape`：太阳光晕形状
- `sky_zenith_color` / `sky_horizon_color`：天顶/地平线颜色 `[R,G,B]`

### 2. 光照 `minecraft:lighting_settings`（1.21.80）
- `directional_lights.orbital.sun/moon`：各自 `illuminance`（照度）+ `color`（颜色），均为时间关键帧
- `directional_lights.orbital.orbital_offset_degrees`：轨道偏移角（**全包须一致，不可混合**）
- `directional_lights.flash`：点闪光 `illuminance` + `color`
- `emissive.desaturation`：自发光去饱和
- `ambient`：`color`（如 `#FFFFFF`）+ `illuminance`
- `sky.intensity`：天空强度

### 3. 色彩分级 `minecraft:color_grading_settings`（1.21.90）
- `color_grading.midtones`：`contrast`/`gain`/`gamma`/`offset`/`saturation`，各为 `[R,G,B]` 系数
- `color_grading.temperature`：`enabled` / `temperature`（K，如 6500）/ `type`（`color_temperature`）
- `tone_mapping.operator`：`generic` 等（**全包须一致，不可混合**）

### 4. 水体 `minecraft:water_settings`（1.21.120）
- `particle_concentrations`：`chlorophyll` / `suspended_sediment` / `cdom`
- `caustics`：`enabled` / `frame_length` / `scale` / `power`（**全包须一致**）
- `waves`：`enabled`（**全包须一致**）/ `frequency` / `octaves` / `depth` / `speed` / `shape` / `pull` / `mix` / `frequency_scaling` / `speed_scaling`

### 5. 天空盒 `cubemaps/`（1.21.130+）
- 官方样例包未提供实例，无法给出权威字段模板
- 已在 client biome 中确认标识符组件 `minecraft:cubemap_identifier`，其 schema 原文要求 identifier 指向 `cubemaps/` 目录下合法 Cubemap JSON
- 需要时用 Bedrock Editor 生成，或查官方文档（见 `07_` 号第 26 行链接）

## 三、时间关键帧（keyframe）语法

数值既可写单值，也可写 `{"时间点": 值}`：
- 0 = 正午，0.25 = 日落，0.5 = 午夜，0.75 = 日出，1 = 次日正午
- 引擎在关键帧间**线性插值**
- 颜色类关键帧值为 `[R,G,B]`

官方 `lighting/global.json` 的太阳照度就是典型多关键帧：正午 100 → 日落前 1 → 日落 0 → 日出后回升。

## 四、群系绑定与混合（官方 07 号文档）

1. 一类可放多个实例，只要**文件名唯一 + JSON 内 `identifier` 唯一**。
2. **保留文件名 = 全局默认**：上述四个默认文件的 identifier 自动作为全局值，除非某 biome 显式指定。
3. client biome 里用组件引用：
   - `minecraft:atmosphere_identifier` → `atmosphere_identifier`
   - `minecraft:color_grading_identifier` → `color_grading_identifier`
   - `minecraft:lighting_identifier` → `lighting_identifier`
   - `minecraft:water_identifier` → `water_identifier`
   - `minecraft:cubemap_identifier` → `cubemap_identifier`
4. **1.21.90 起**原版包自带逐群系配置，优先级高于内置全局值和自定义包全局文件。
5. 混合方式：大气/色彩分级/光照/cubemap 按**玩家位置**空间混合；水体按**水体几何位置**混合（可远眺看出不同群系的水色）。
6. **不可混合参数**（一个包内所有同类 schema 必须一致）：tone mapping 算子、orbital offset 角度、caustics 参数、waves 开关。违反可能导致配置失效或报错。

## 五、多包叠加注意（呼应 18 号）

- 这些配置 JSON 和 texture_set 一样，**高优先级包整体替换同名定义，不合并**。
- `pbr/global.json` 是全局单例，两包都定义会冲突——转换器的"叠加模式"已规避。
- 若转换包（仅贴图层）与一个带完整配置层的 PBR 包叠加：贴图由转换包提供，大气/光照等由下层包提供，各司其职通常不冲突；但要保证"全包一致"的四类参数不被转换包破坏（转换包不含这些配置，天然满足）。
